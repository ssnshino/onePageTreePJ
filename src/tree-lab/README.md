# OLD OAK TREE LAB

A focused tuning scene for the exact OLD OAK generator used by the main one-page world.

Build:

```bash
npm install
npm run build:tree-lab
npm run verify:tree-lab
```

Output:
`dist/tree-lab-old-oak.html`

The lab is intentionally visually plain. If the tree only looks good inside the lake scene, the tree is not finished.
