# TREE LAB UI v3 — 日本語 / 段階開示

Created: 2026-09-25T10:15:00+09:00

## Problem
TREE LAB accumulated too many equally prominent sliders.

## New hierarchy

### まず触る
Only seven primary controls:
- 樹高
- 幹の太さ
- 樹冠の横広がり
- 枝の方位均等化
- 葉の密度
- 内側の葉量
- 空の抜け

### 空間充填（逆フラクタル実験）
- 引力点表示
- 未到達だけ表示
- 枝の到達率
- 方位カバー
- 最大空白角

### 詳細設定
All previous fine controls remain available, but are collapsed by default.

No tuning capability is deleted.

## Japanese labels
Normal interaction labels are Japanese.
Technical proper nouns/metrics remain where traceability benefits:
Bedford Oak, Space Colonization, FPS, TRI, DRAW, GEO, TEX, DPR.
