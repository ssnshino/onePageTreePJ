# BEDFORD OAK PHOTO MATCH PLAN

Created: 2026-09-24T23:02:00+09:00

## Target
Reproduce the visual character of the Bedford Oak rather than inventing a generic "nice old oak."

## Phase 1 — normalized proportion match
Targets:
- spread / height >= 1.74
- trunk diameter / height ~= 0.098

TREE LAB reports these live.

## Phase 2 — silhouette
Use FRONT + SILHOUETTE and compare against the 2022/2012 Bedford Oak photos.

Priorities:
1. crown width
2. crown start height
3. primary scaffold direction
4. trunk mass
5. asymmetric gaps

## Phase 3 — branch history
After proportion match:
- introduce missing/broken limb history
- uneven scaffold dominance
- more convincing junction blending

## Phase 4 — foliage mass
Only after skeleton silhouette is convincing:
- leaf density distribution
- canopy clumping
- dome-normal lighting
- wind

## Candidate preset 01
Experimental mapping:
- height 10.50
- trunk radius 0.52
- trunk clear 0.10
- root flare 1.18
- junction collar 0.34
- primary count 10

Human review decides whether this mapping actually resembles the photographed tree.
