# ONE-PAGE THREE.JS REALISTIC WORLD v0.6 — NATURAL ASSET QUALITY PLAN

Created: 2026-09-24T09:39:00+09:00

## Purpose
v0.5を基準に、水・山の及第点を維持しながら、画面全体の写実感を大きく下げている木と岩を重点改善する。

## Primary Targets

### Trees
- natural silhouette
- branch hierarchy / taper / curvature
- foliage card / alpha foliage research
- crown breakup
- bark detail
- near / mid / far LOD
- individual variation
- optional wind sway

### Rocks
- geological fracture planes
- non-spherical base topology
- layered displacement
- erosion / edge breakup
- roughness variation
- moss / lichen
- wet rock near shoreline
- boulder / stone / outcrop distinction

## Non-target
- Water system rewrite
- Mountain system rewrite
- Game mechanics
- First-person movement
- Major UI redesign

## Research First
Three.js official examples, graphics literature, GitHub implementations and Three.js forumを調査してから実装する。

## Regression
Maintain:
- v0.5 water / sky / mountain composition
- OrbitControls
- reflection
- smartphone fallback
- one-page HTML execution

## QA
- JavaScript syntax
- browser boot
- desktop
- smartphone
- near tree visual review
- silhouette review
- rock close-up review
- FPS / triangles / draw-call observation
- Human recording review

## Success Condition
「木＝図形」「岩＝ジャガイモ」という第一印象を消し、水・山と同程度以上の説得力へ引き上げる。
